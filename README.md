## Static Site Generator
A **Python** program that generates static sites by parsing Markdown content and converting it into HTML. This project was developed as part of the [Boot.dev](https://www.boot.dev) curriculum.

## Get Started
Can be run using **./build.sh** in the terminal. The generated HTML files will be available in the **/docs** directory.

The website generated using the current contents can be accessed at [this link](https://roxana-xdx.github.io/static-site-generator/).

## Features
- Converts Markdown to HTML
- Supports headings, links, images, code blocks, etc.
- Generates a complete static site structure

## Project Structure
- `src/` - Source code for the generator
- `content/` - Markdown files to be converted
- `docs/` - Generated HTML output
